# Lexwright v0.1.0 — First MVP

Lexwright is a minimal, keyboard-first, ephemeral text scratchpad with
programmable expansion rules for Linux and Wayland. Invoke it, write or expand
text, copy, and close. On Hyprland, the default scratch window floats without
rearranging existing tiles.

## Accepted interaction

| Action | Result |
| --- | --- |
| Launch `lexwright` | Fresh scratch overlay |
| Enter with text | Copy to clipboard and exit |
| Enter with blank or whitespace-only text | Exit; preserve clipboard |
| Shift+Enter | Newline |
| Escape | Discard and exit; preserve clipboard |
| Open `rules` | Configure persistent expansion rules |
| Open `appearance` | Independently adjust editor and interface fonts |
| Launch `lexwright --editor` | Access the retained durable editor |

Scratch text is never persisted. Expansion rules and preferences are. Harper
and the secondary language-analysis tools are not part of the default scratch
workflow.

## Requirements and build

Built with Rust and egui/eframe. Intended for Linux and Wayland; floating
placement is Hyprland-specific. Copying nonempty scratch text requires
`wl-copy` (the `wl-clipboard` package).

```sh
cargo install --path . --locked
```

This is a **source release**. It does not include prebuilt binaries or
packages.

## Acceptance and maintenance

The interactive design was accepted after real-world use on 2026-10-08.
The release candidate passed GitHub Actions checks for compilation, tests,
Clippy, and formatting. This does not assert exhaustive hardware testing.

The MVP UX is intentionally frozen. Correctness, startup, clipboard, Wayland
integration, and expansion defects qualify for maintenance fixes; changes to
interaction design require a separate deliberate decision.
